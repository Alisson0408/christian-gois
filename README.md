# Christian Gois — Psicanalista

Site profissional desenvolvido para **Christian Gois**, com foco na apresentação de sua atuação na área de Psicanálise, fortalecimento da presença digital e criação de um canal profissional para apresentação de serviços e contato.

O projeto foi desenvolvido com uma proposta visual elegante, acolhedora e profissional, utilizando uma identidade baseada em tons de verde oliva, verde sálvia, creme, off-white e detalhes em dourado suave.

## 🚀 Sobre o projeto

O site foi desenvolvido para apresentar de forma clara e profissional:

- Apresentação profissional
- Áreas de atuação
- Informações sobre Psicanálise
- Serviços oferecidos
- Contato profissional
- Integração com WhatsApp
- Integração com redes sociais
- Navegação responsiva para computadores, tablets e celulares

O projeto prioriza uma experiência visual limpa, moderna e acessível, facilitando o contato entre o profissional e seus potenciais clientes.
